# RAG-Retrieval-Augmented-Generation-AI-agent
This project is a production-ready RAG (Retrieval-Augmented Generation) AI agent built in Python that lets users chat with their own PDF documents in a Streamlit web interface. It uses FastAPI to expose backend endpoints, Qdrant as a local vector database for high-performance similarity search, and LlamaIndex to load, chunk, and index PDF content .
